### Descripción del Proyecto

Este proyecto es una recreación de un shooter espacial vertical en 2D, desarrollado completamente en Unity. El objetivo fue implementar desde cero las mecánicas de juego fundamentales y gestionar un ciclo de juego completo.

-   **Desarrollo de Mecánicas:** Se utilizó C# para programar todos los comportamientos, incluyendo el movimiento del jugador, la física de los disparos, las oleadas de enemigos y los power-ups.
-   **Gestión de Interfaz:** Implementación de un `UIManager` para manejar elementos visuales como la puntuación, las vidas del jugador y las pantallas de juego.
-   **Optimización:** Uso de `Prefabs` para la instanciación eficiente de enemigos y proyectiles, y un `SpawnManager` para controlar la aparición de oleadas de forma dinámica.
-   **Ciclo de Juego Completo:** Creación de un ciclo que incluye inicio, juego, sistema de vidas y pantalla de "Game Over".

### ⚙️ Tecnologías Utilizadas

`Unity IDE` `C#` `Game Design` `UX Design`
